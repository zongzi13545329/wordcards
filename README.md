# 词卡速刷

手机上用的背单词 App（网页版，可安装到桌面、离线使用）。

功能：认识/不认识速刷与多轮重刷、跨词书错词本（记不住 / 读错了）、沉浸刷词、随身听、随手拼、听写、英选中、中选英、例句填空、学习统计、备份与恢复。

数据只保存在使用者自己的浏览器里（IndexedDB），不上传任何服务器。本仓库只包含 App 本身，不包含任何词书内容。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `wordcards`），选 Public。
2. 在仓库页面点 **Add file → Upload files**，把本压缩包里的全部文件拖进去，点 **Commit changes**。
3. 打开仓库的 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`、文件夹选 `/ (root)`，点 **Save**。
4. 等一两分钟，页面顶部会显示网址：`https://你的用户名.github.io/wordcards/`。

## 在安卓手机上安装

1. 用 Chrome 打开上面的网址。
2. 点右上角 ⋮ → **安装应用**（或「添加到主屏幕」）。也可以在 App 的「设置」页点「安装」。
3. 之后从桌面图标打开，全屏运行，没网也能用。

## 导入词书

1. 把 `词卡速刷-词书包.json` 传到手机上（网盘、邮件、聊天软件都行）。
2. 打开 App → **设置 → 导入备份或词书包**，选这个文件，确认导入。
3. 到「词书」页切换要刷的词书。

注意：词书包不要上传到 GitHub 仓库里。

## 备份

数据在浏览器里，卸载 App 或清除 Chrome 的网站数据会一起删除。在「设置 → 导出备份」可以把词书、进度、错词本和统计存成一个文件；换手机时在新手机上「导入备份」即可。

## 想要 APK 安装包（可选）

打开 https://www.pwabuilder.com ，输入你的 Pages 网址 → **Package for stores → Android** → 下载生成的 APK，在手机上安装（需要允许安装未知来源应用）。

## 更新

以后有新版本时，只需在仓库里用新的 `index.html` 替换旧文件。App 联网打开时会自动用上新版本。
